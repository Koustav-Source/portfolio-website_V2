## Portfolio Architecture

The application follows a component-driven React architecture.

```text
Portfolio
│
├── App.tsx
│
├── Components
│   ├── Navbar
│   ├── Hero
│   ├── AboutSection
│   ├── EngineeringProfile
│   ├── FeaturedWork
│   ├── ProjectCaseStudyModal
│   ├── ExperienceTimeline
│   ├── EducationSection
│   ├── ResumeSection
│   ├── ResumeModal
│   ├── ContactSection
│   ├── AdminPanel
│   ├── ThreeSystemsCanvas
│   └── Footer
│
├── Data
│   ├── profile.ts
│   ├── projects.ts
│   ├── experience.ts
│   ├── education.ts
│   ├── skills.ts
│   └── certifications.ts
│
├── Assets
│   └── images
│
└── Public
    ├── avatar.jpg
    └── resume
        └── Koustav-Dey-Resume.pdf
```

The separation between **UI components**, **structured profile data**, and **static assets** makes the portfolio easier to maintain and update without rewriting the presentation layer.

## Local Development

### Prerequisites

Install:

* Node.js
* npm
* Git

### Clone the repository

```bash
git clone https://github.com/Koustav-Source/portfolio-website_V2.git
cd portfolio-website_V2
```

### Install dependencies

```bash
npm install
```

### Environment variables

Create a local environment file:

```bash
.env
```

Use the provided example as a reference:

```bash
.env.example
```

Never commit real API keys or credentials to Git.

Example:

```env
GEMINI_API_KEY=your_api_key_here
APP_URL=http://localhost:3000
```

### Start the development server

```bash
npm run dev
```

The application runs through Vite.

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```

### Type-check the project

```bash
npm run lint
```

## Environment & Security

This repository intentionally does **not** contain production API credentials.

Environment-specific secrets should remain in local environment files or the deployment platform's secret-management system.

```text
.env
.env.local
.env.*.local
```

should never be committed to the repository.

The committed `.env.example` contains placeholders only.
